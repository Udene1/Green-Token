# Kenneth Elioku — Engineering Portfolio

A personal engineering portfolio for backend and systems engineering, automation infrastructure, operational software, and evidence-driven products.

## Stack

- Next.js 14 / React 18
- TypeScript
- Responsive custom CSS; no component-library dependency

## Local development

```bash
npm install
npm run dev
```

## Build verification

```bash
npm run build
```

## Portfolio integrity

Project descriptions are intentionally bounded to the work and engineering patterns represented in each repository. Prototype status, ongoing work, and UI refinement are disclosed rather than presented as production-ready products.

## Deployment

Intended for Vercel, connected to the `main` branch.
